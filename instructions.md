## Important Instruction

* Never ever push directly into the **main** branch.
* Before developing or adding a new feature, create an **Issue** on GitHub first.
* Create a new branch for each feature you implement.
* Once the feature is ready, create a Pull Request (PR) and get it reviewed before merging it into main.
* The frontend should be deployed from day one, and we should `test it live` in the browser as we build.
* `Test cases` should be included along with the features being introduced.
